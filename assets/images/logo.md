# Logo de l'application Mam Buudu

## Description
Logo principal de l'application représentant un arbre généalogique moderne.

## Spécifications
- Format : PNG avec transparence
- Taille principale : 120x120px
- Résolution 2x : 240x240px
- Icône adaptative pour différentes plateformes

## Utilisation
- Landing screen (principal)
- Écran splash
- Icône de l'application
- Favicon web

## Note
Pour le développement, nous utilisons Icons.family_restroom en attendant le logo final.
