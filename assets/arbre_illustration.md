# Illustration pour Landing Screen

## Description
Cette image représente un arbre généalogique stylisé avec :
- Racines profondes symbolisant les ancêtres
- Branches représentant les générations
- Feuilles montrant la vitalité familiale
- Design moderne et épuré

## Dimensions recommandées
- Largeur : 400px
- Hauteur : 400px
- Format : PNG avec transparence
- Résolution : 2x (800x800px pour les écrans Retina)

## Palette de couleurs
- Vert forêt : #2E7D32
- Vert clair : #81C784
- Bleu ciel : #87CEEB
- Blanc : #FFFFFF

## Note
Pour le développement, nous utilisons l'icône Material Icons `Icons.family_restroom` 
qui remplace temporairement cette illustration.

Pour la production, remplacer par une illustration personnalisée créée par un designer
ou utilisez des services comme :
- Figma
- Canva
- Adobe Illustrator
- Un designer freelance
